          ⚙
          
Configuración del Generador y Túnel MarioGPT

        

        
      


      

        

          Administra la fuente para generar los niveles personalizados (con IA). Puedes alternar entre el servidor dedicado, el túnel SSH hacia el clúster HPC o la generación nativa local.
        


        
        

          
          
          
        


        
        

          

            ⚡ Servidor Dedicado del Prof. Jeisson: Conexión directa HTTP dentro de la red UCR. No requiere llaves SSH ni abrir túneles en cada máquina.
          

          

            
            
          

        


        

          

            🚇 Túnel SSH al Clúster: Redirige el puerto local hacia el nodo GPU asignado por Slurm en el clúster.
          

          
          

            

              
              
              Ej: mariogabriel.cordero@172.16.24.2
            

            

              
              
              Puerto local y remoto (default: 8888)
            

          


          

            
            

              
              
            

            Slurm asigna el servicio dinámicamente a nodos como cngpu001 o cngpu002.
          


          
          

            

              Comando SSH interactivo generado:
              
            

            ssh -N -L 8888:cngpu002:8888 mariogabriel.cordero@172.16.24.2
          

        


        

          

            💻 Generación Local Nativa: Ejecuta MarioGPT directamente con PyTorch en esta máquina. Funciona 100% offline sin red.
